# Classroom Gradebook

A small, responsive gradebook for keeping student scores organized and reviewing class progress.

**Live demo:** [Open Classroom Gradebook](https://avi-808.github.io/classroom-gradebook/)

## Features

- Record scores for up to eight assessments.
- Add students and assessments, and update scores inline.
- Automatically calculate student averages, letter grades, class average, and passing rate.
- Review class performance and grade distribution charts.
- Search and sort the roster.
- Export the gradebook as a CSV file.
- Save changes in the current browser using local storage.

## Run it

Open `index.html` in a modern browser. No installation or account is required.

The included roster uses generic placeholder names and starts with blank scores. All changes are stored on the device and browser where the site is opened. Export a CSV backup before clearing browser data.

## Built with

HTML, CSS, and vanilla JavaScript.
